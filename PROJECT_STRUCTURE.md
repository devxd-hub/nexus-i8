## 2. Key Directories & Domain Mapping

### Where Frontend Code Lives
- **Path**: [`/frontend/src`](file:///frontend/src)
- **Framework**: React 19 with Vite, Tailwind CSS, Motion (Framer Motion), Three.js / Paper Design Shaders.
- **Pages**: [`/frontend/src/pages/`](file:///frontend/src/pages/) contains all top-level route views:
  - `HomePage.tsx`: Editorial hero, brand narrative, interactive showcase, live prototype bench.
  - `AboutPage.tsx`: Interactive multi-act horizontal narrative and philosophy.
  - `TeamPage.tsx`: Leadership timeline, coordinators, mentors, and member directory.
  - `ProjectsPage.tsx`: Interactive project dossiers, archive cards, and tech specs.
  - `GalleryPage.tsx`: High-resolution photography mosaic with lightbox inspection.
  - `ContactPage.tsx`: Community contact and recruitment submission forms.

### Where Images Live
- **Root**: [`/frontend/images/`](file:///frontend/images/)
- All image assets used across the application are centralized with zero content changes:
  - **Team Portraits**: [`/frontend/images/team/`](file:///frontend/images/team/) — WebP and high-res portraits for leadership, coordinators, mentors, and crew members.
  - **Gallery Photography**: [`/frontend/images/gallery/`](file:///frontend/images/gallery/) — Event photography, keynotes, workshops, and cohorts.
  - **Project Visuals**: [`/frontend/images/projects/`](file:///frontend/images/projects/) — Architectural SVG diagrams, interface sketches, and voxen prototype.
  - **Event Graphics**: [`/frontend/images/events/`](file:///frontend/images/events/) — High-res photography from industry events and faculty dialogue.
  - **Logos & Badges**: [`/frontend/images/logos/`](file:///frontend/images/logos/) — Canonical NEXUS transparent X logo (`NEXUS-removebg-preview-1.png`), vector SVGs, Coding Ninjas dark/light logos, and favicons.
  - **Mascot & Sprites**: [`/frontend/images/misc/`](file:///frontend/images/misc/) — Complete 25-state pixel-art penguin mascot frames and ASCII artwork.

### Where Backend Code Lives
- **Path**: [`/backend/`](file:///backend/)
- **Framework**: Node.js + Express + TypeScript + SQLite.
- **Routes**: [`/backend/routes.ts`](file:///backend/routes.ts) registers all public and authenticated endpoints under `/api`.
- **Services**: [`/backend/services/`](file:///backend/services/) contains core business logic:
  - `media.service.ts`: Media upload pipeline, MIME verification, SHA-256 deduplication, and lifecycle storage management.
  - `audit.service.ts`: Security event recording, login tracking, and mutation auditing.
  - `notificationHook.service.ts`: Extensible event hooks for submission and recruitment workflows.
- **Database Code**: [`/backend/db/`](file:///backend/db/)
  - `client.ts`: Connection pooling and transaction management (`runTransaction`).
  - `schema.sql`: Complete relational database schema with foreign key cascades and indices.
  - `migrate.ts`: Automated schema migration executor.
  - `seed.ts` / `seedData.ts`: Database seeder synchronized with authentic NEXUS datasets.
- **Authentication & Security**: [`/backend/middleware/`](file:///backend/middleware/) and [`/backend/domains/admin/`](file:///backend/domains/admin/)
  - `auth.ts`: Bearer token validation, role-based authorization (`admin`, `super_admin`), and session timeout enforcement.
  - `rateLimiter.ts`: In-memory IP-based rate limiting with standard RFC headers.
  - `securityHeaders.ts`: Strict production security headers (`CSP`, `X-Content-Type-Options`, `X-Frame-Options`).
  - `spamProtection.ts`: Honeypot fields, rate windows, and payload sanitization.

## 3. Root Level Classification & Justification

Every file remaining at repository root has a strict, essential purpose:

| File | Classification | Justification |
| :--- | :--- | :--- |
| `package.json` | REQUIRED ROOT CONFIG | Single source of truth for dependencies, run scripts, and module resolution. |
| `package-lock.json` | REQUIRED ROOT CONFIG | Deterministic dependency lockfile. |
| `tsconfig.json` | REQUIRED ROOT CONFIG | Root TypeScript compiler configuration and path mapping (`@/*` -> `./frontend/src/*`). |
| `vite.config.ts` | REQUIRED ROOT CONFIG | Build and dev server configuration configured with frontend root and backend proxy. |
| `vercel.json` | BUILD/DEPLOYMENT | Deployment routing and static build configuration for host environments. |
| `metadata.json` | REQUIRED ROOT CONFIG | Platform capability descriptors. |
| `.gitignore` | REQUIRED ROOT CONFIG | VCS ignore patterns for artifacts, `node_modules`, `dist`, and database files. |
| `.env.example` | DOCUMENTATION / CONFIG | Template for environment variable configuration. |
| `bun.lock` | BUILD/DEPLOYMENT | Alternative package manager lockfile. |
| `README.md` | DOCUMENTATION | Quickstart guide and entry documentation. |
| `CHANGELOG.md` | DOCUMENTATION | Historical changelog of features, migrations, and fixes. |
| `PROJECT_STRUCTURE.md` | DOCUMENTATION | Repository structural blueprint (this document). |
| `STRUCTURE_FINAL_REPORT.md` | DOCUMENTATION | Final migration verification and test report. |

## 4. Development Commands Quick Reference

```bash
# Frontend Development Server (Port 3000)
npm run dev

# Backend API Server
npm run server:dev

# Run Database Migrations & Seeds
npm run db:migrate
npm run db:seed

# Run Static Typecheck & Linting
npm run lint

# Run Complete Backend Test Suite (163 tests)
npm run test

# Production Build
npm run build
```
